# Agent 全量评测报告

报告日期：2026-10-09。依据：[评测方案](Agent评测方案.md)、[执行记录](Agent全量评测执行记录.md)。

## 结论

正式三轮141条消息全部完成采集，无缺测、无预算中止。135条正常业务消息全部返回completed；3条工具超时测试诚实降级，3条零额度测试返回预期error且未调用上游。没有观察到非预期的链路超时或内部异常。

**正常任务硬规则初判71/114（62.3%），三轮均达标22/38（57.9%）。这不是最终答案正确率。** 主要缺口是需求提取、历史细粒度回答、记忆问答路由、个性化落实和规划时段完整性。HTTP/SSE能返回结果与回答满足需求必须分开看。

推荐与天气的硬规则结果较好；其中R06“不吃辣”仅证明偏好被保存并进入需求，推荐输出与普通推荐相同，尚不能证明个性化效果。收藏是否真正影响规划、餐食安排是否合理等仍待人工复核。当前不建议把62.3%或“推荐100%”直接写成简历上的整体准确率。
