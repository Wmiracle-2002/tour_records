# 核心评测用例清单

日期：2026-10-08；版本：`core-v1`。本清单供人工阅读；完整逐步判分条件和预置引用以 [cases.json](../server/evaluation/cases.json) 为准，方法见 [Agent评测方案](Agent评测方案.md)。所有样例当前为真实 LLM + 合成工具数据的 A 轨；部分已小额试跑，完整正式基线尚未运行，结果见 [试跑报告](Agent评测试跑报告-2026-10-08.md)。

历史回答验收口径：H01只列城市；地点仅包含景点，按城市合并与去重；美食按城市单列；H05明确同时问两者时分别列景点和美食。不得把餐饮混入“去过的地点”。

每场景独立初始化预置账号数据；一个场景内按顺序发送，标注“新会话”时才切换会话。合成日期固定为北京时间 2026-10-08 10:00。Alice 去过南京两次、苏州一次、上海一次；Bob 仅去过哈尔滨，两者数据不能串用。

共 40 场景，其中正常业务 38 场景、故障注入 2 场景。三次正式重复共 120 场景运行、141 条消息步骤；正常任务成功率和故障处理成功率分别统计。

长会话 M05 从未压缩的 26 条原始消息开始；前置数据量超过压缩触发阈值，题目检查是否真正发生摘要及原文保留。E01 注入 POI 查询超时，E02 设置独立测试账号零额度。它们不能直接发送给生产环境来完成验收。
