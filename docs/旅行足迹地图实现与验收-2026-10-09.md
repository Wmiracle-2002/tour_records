# 旅行足迹地图实现与验收

日期：2026-10-09。进度功能版本33e17fc推送后开始实现地图；模拟器发现的进度补充修复已另推送c4607bc。地图首版本地实现及验收完成，未提交。

## 实现

- 记录页保留原列表，增加列表／地图切换。
- 全国展示省级轮廓；点击省份，地图适配省级范围；点击城市，展示该市多次旅行，复用原TripCard及详情、添加小记录入口。
- 显示出行次数，有记录地区为绿色；无记录城市明确显示空状态。
- 直辖市直接对应城市；省直管县级市仍在城市速选中。返回全国及Android返回键支持回到全国。
- 只读取已有当前账号的Room旅行数据流，不发送定位请求、不调用LLM、不新增后端接口或数据库表。

## 边界与映射

28份GeoJSON共3,877,280字节，约3.88MB，随APK打包，离线可用。下载脚本校验Polygon/MultiPolygon、坐标范围、父级和唯一编码，manifest保存来源与哈希。全国35个Feature均保留，含附属边界，不以方块代替真实轮廓。

目录中的新星市659011、白杨市659012缺对应边界；速选仍可查看其记录，并提示缺少边界。空编码或不在现有可选城市目录的旧旅行不冒猜对应，显示未匹配数量，仍可通过原列表查看。

绘制与点击使用同一墨卡托投影和视口变换，正确处理内环和多岛。城市筛选按CityEntity.cityCode对应本地cityId，日期倒序，不按模糊名称关联。

## 手机手动检查

1. 覆盖安装新版APK，在记录页点击地图；全国视图中有旅行的省份应为绿色。
2. 点击江苏，省地图适配；点南京或城市速选，应显示南京的各次旅行。
3. 点一个未去过的城市，应为空，不出现其他城市记录。
4. 点旅行卡片进入原详情，编辑或新增后返回，次数与内容应更新。
5. 返回全国、切回列表、切换底部页面，不应闪退；直辖市直接显示旅行。
6. 有无匹配编码的旧记录时，确认提示与列表保留；新星、白杨应能通过速选查看。

首版没有道路底图、路线导航、GPS定位或景点精确坐标。
